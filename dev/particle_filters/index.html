Particle filters

AnalogDataAssimilation.forecast — Method
forecast(da, yo, AnPF(np); progress=true, rng=Random.default_rng())

Run a sequential importance-resampling particle filter using np particles. NaN marks a missing observation; infinite observations are rejected. Resampled particles receive equal weights. The small Gaussian perturbation with covariance da.B / 100 after each forecast is retained from the original AnDA implementation. Pass an explicit random number generator for reproducibility.

source

AnPF(np) requires at least two particles. Missing observation components may be marked with NaN; infinite values are rejected. Estimates are computed from normalized importance weights before multinomial resampling, and resampled particles receive equal weights. The filter retains the small da.B / 100 Gaussian perturbation after each forecast. Set using Random and pass rng=MersenneTwister(seed) to forecast for reproducible sampling.
