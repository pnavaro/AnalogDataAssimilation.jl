Ensemble filters

AnalogDataAssimilation.AnEnKF — Type
AnEnKF(np)

Construct an ensemble Kalman filter with at least two members. forecast accepts an rng keyword (defaulting to Julia's task-local RNG) for reproducible sampling. Missing observations are represented by NaN; infinite observations are rejected.

source
AnalogDataAssimilation.forecast — Method
forecast(da, yo, mc; progress=true, rng=Random.default_rng())
  • da: DataAssimilation
  • yo: Observations
  • mc: Monte Carlo method
  • progress: display the progress bar.

Apply stochastic and sequential data assimilation technics using model forecasting or analog forecasting.

source

AnEnKF(np) requires at least two ensemble members. Missing observation components may be marked with NaN; infinite values are rejected. Set using Random and pass rng=MersenneTwister(seed) to forecast to make its sampling reproducible.
